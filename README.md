# Vibe Launcher

Простой Android-лаунчер (MVP), созданный в MargyCode.

## Что реализовано

- Сетка приложений 4x6 на главном экране.
- Поиск по приложениям в капсуле над док-баром.
- Док-бар на 4 иконки.
- Долгое нажатие по иконке — перетаскивание (grid/dock).
- Долгое нажатие по пустому месту — круглая кнопка настроек снизу.
- Настройки: переключатель флагманских/простых анимаций.
- Запуск приложений с анимацией масштабирования от иконки.

## Ограничения MVP

- Проект не собирался в этом окружении (нет Android SDK/Gradle/Java).
- Drag-and-drop и поведение лаунчера стоит проверить на реальном устройстве.
- Анимация "закрытия обратно в иконку" ограничена системными возможностями Android для внешних приложений; реализован запуск через `ActivityOptions.makeScaleUpAnimation`.

## Сборка

Откройте папку `launcher` в Android Studio и соберите APK обычным способом (Gradle/Android Studio). После сборки APK можно установить на устройство.
